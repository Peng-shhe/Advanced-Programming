# 仙剑98柔情版 存档修改器

基于 Tkinter 的《仙剑奇侠传 98 柔情版》存档（`.RPG`）可视化修改工具。纯 Python 标准库实现，无需安装第三方依赖。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 属性修改 | 修行、最大体力/真气、体力/真气、武术、灵力、防御、身法、吉运（直接输入数字） |
| 装备修改 | 每角色 6 个披挂栏位（头部/披风/衣甲/武器/靴子/饰品），选项自动来自当前背包 |
| 仙术修改 | 每角色 32 个法术位，下拉选择（选"无"清空该槽） |
| 背包物品 | 全物品数量表（234 项，缺失显示 0），选中物品设置数量（0 = 移除） |
| 金钱修改 | 32 位小端读写，游戏界面最多显示 6 位数（≤999999） |
| 自动备份 | 首次保存时自动生成 `原文件名.RPG.bak`，原档损坏可用其恢复 |

## 使用方法

```bat
python pal_save_editor_gui.py
```

1. 菜单 **文件 → 打开存档**，选择 `.RPG` 存档文件
2. 在各角色页签修改属性、披挂、仙术；在 **背包物品** 页签增减物品与金钱
3. 菜单 **文件 → 保存**（或 **另存为**）写回存档，保存时自动备份

> 属性输入框、装备/仙术下拉框、金钱输入框的修改在**点击保存时统一生效**；背包物品页的"设置选中物品数量"则**立即写入内存数据**，保存时一并落盘。

## 界面说明

- **角色页签**：仅显示当前存档中在队的角色（最大体力为 0 的槽位视为空，不显示）
- **披挂**：下拉框选项来自背包中对应部位的物品（如武器栏只列出 0xA3–0xC3 的武器），选"卸下 (0)"清空该栏
- **背包物品页**：表格列出全部 234 种物品的代码、名称与当前数量；输入数量后点"设置选中物品数量"即生效

**在背包中新增装备后可直接装备**：数量设置生效时，角色页的披挂下拉框会自动刷新，新装备立即可选，无需保存后重新打开存档。

## 存档结构速查（DOS/98 版）

| 区域 | 偏移 | 结构 |
| --- | --- | --- |
| 金钱 | 0x28–0x2B | 32 位小端 |
| 角色属性区 | 0x200 + 0x044 起 | 字段步进 0x0C，角色步进 2 字节 |
| 披挂区 | 0x200 + 0x080 起 | 6 栏，栏步进 0x0C，角色步进 2 字节 |
| 仙术区 | 0x37C 起 | 每 12 字节一轮（6 人 × 2 字节），每角色 32 个法术位 |
| 背包物品区 | 0x6C0–0xCBF | 256 槽，每槽 6 字节（代码 + 数量 + 保留） |
| 场景物件/事件状态表 | 0xCC0 起 | **只读，严禁修改** |

角色序号固定映射：0=李逍遥、1=赵灵儿、2=林月如、3=巫后、4=阿奴（5=盖罗娇，boss 专用槽，修改器不显示、不修改）。

## 重要约束（修改须知）

- **物品区上限 256 槽**：写入按代码升序从槽 0 重排并尾部清零，严格限制在 0x6C0–0xCBF 内；越界会覆盖 0xCC0 起的场景状态表，导致游戏内位置/事件错乱
- **0xCC0 起为场景物件/事件状态表**：任何写操作都不得触碰
- **装备代码合法区间**（源自游戏自带攻略分类表）：武器 0xA3–C3、头部 0xC4–CF、衣甲 0xD0–E0、披风 0xE1–EA、靴子 0xEB–F7、饰品 0xF8–10E 及玉佛珠 0x112；0x10F 起为剧情杂物，不可装备
- **物品数量范围 0–99**
- **数值字段为 16 位小端**（金钱为 32 位小端），工具已自动处理

## 常见问题

**Q：修改后游戏里没变化？**
确认已点"保存"，且游戏需重新读取存档（回主菜单再读档）才会生效。

**Q：存档被改坏了？**
同目录下找 `原存档.RPG.bak`（首次保存前的原始备份），改回 `.RPG` 即可恢复。

**Q：想加的物品在列表里找不到？**
物品页表格包含全部 234 种已知物品（代码 0x3D–0x126），滚动查找或按代码区间定位；装备类物品建议按上面的合法区间核对栏位。
